# 창밖날씨(WINDOW SCAPE) 기획서

> 이 문서는 2026-11-05에 이미 출시된 v0.5.0 코드·README·개발 글을 보고 거꾸로 정리했다. 구현된 기능을 사용자가 요구한 기능으로 보고 썼다.
> 함께 보기: [설계서](설계서.md) · [구현도](구현도.md) · [결정기록](결정기록.md) · [들어가기 모드 캐릭터 시안](explore-character.md)

## 한 줄 소개

바탕화면에 작은 창을 하나 내고, 그 너머 3D 미니어처 풍경으로 오늘 날씨를 보여 주는 데스크톱 위젯. 비가 오면 창밖에도 비가 오고, 해가 지면 창밖 마을에 불이 켜진다.

## 왜 만들었나

- 인스타그램에서 Pascal Mager(@hellothere.de)의 릴스를 봤다. Blender와 Three.js로 만든 작은 섬이 실제 날씨에 맞춰 바뀌는 영상.
- 원작은 웹사이트였다. 바탕화면 구석에 늘 띄워 두고 싶어서 위젯으로 만들었다.
- 원작에서는 "날씨에 따라 변하는 3D 미니어처"라는 아이디어만 빌렸다. 모델·코드는 전부 새로 만들었다.
- 근거: [README.ko.md](../README.ko.md), 개발 글 [velog](https://velog.io/@haul/window-scape-weather-diorama-widget)(`dev-post/09-window-scape/post.md`)

## 누가 쓰나

- 바탕화면에 날씨를 늘 띄워 두고 싶은 macOS·Windows 사용자.
- 꾸미기용 위젯을 좋아하는 사람. 정보보다 "창밖을 보는 느낌"이 먼저다.

## 목표

개발 글의 목표 표(`dev-post/09-window-scape/tables/tables.html`)를 옮긴다.

| 목표 | 결정 | 이유 |
|---|---|---|
| 늘 띄워 둘 수 있게 | 웹사이트 대신 Tauri 위젯 | 바탕화면 구석에 계속 두려면 앱이 가벼워야 한다(설치 파일 20MB 안쪽) |
| | 창 크기에 따라 정보량 조절 | 작게 두면 풍경과 기온만 보이는 게 제일 편하다 |
| 미니어처처럼 보이게 | 코드 도형 → Blender 모델 | 코드로 만든 도형은 장난감 블록 느낌이 안 빠진다 |
| | 빛은 굽고 해만 실시간 | 부드러운 그늘을 살리면서 늘 띄워 둬도 가볍게 돌아가야 한다 |
| 오래 봐도 편하게 | 나무·집·사람 덜어내기 | 작은 창에서 빽빽하면 뭐가 뭔지 안 보인다 |
| | 원작은 아이디어만 빌리기 | 모델·코드를 그대로 가져오면 내 것이 아니다 |

## 핵심 시나리오

1. 설치하고 켜면 화면 오른쪽 위에 항상 위로 떠 있다.
2. 현재 위치를 쓰거나 도시를 검색해 고른다. 지금 날씨 그대로 창밖 풍경이 바뀐다.
3. 창을 작게 줄이면 풍경과 기온만, 키우면 7일 예보와 시간별 그래프까지 나온다.
4. 메뉴 막대(Windows는 트레이)의 창문 아이콘에서 바탕화면 고정·항상 위를 바꾸고, 설정에서 투명도를 낮춰 배경처럼 둔다.
5. 테마(하늘섬·해안도로·피렌체 도시·움직이는 성·숲)를 바꿔 본다. 요일을 누르면 그날 날씨가 장면에 반영된다.
6. 사람 아이콘을 누르면 캐릭터가 풍경 안에 내려가 걸어 다닌다(시험 중).

## 기능 목록

### 구현됨 (v0.5.0)

| 영역 | 기능 |
|---|---|
| 테마 | 하늘섬, 해안도로, 피렌체 도시, 움직이는 성, 숲. 하늘섬 외 네 테마는 "모양"을 지평선 풍경 / 미니어처 중 고름 |
| 시간대 | 아침·낮·저녁·밤에 따라 하늘색·햇빛. 밤에는 창문·가로등 불빛 |
| 날씨 | 10가지: 맑음, 구름 조금, 흐림, 바람, 안개, 비, 폭우, 뇌우, 눈, 무지개(비 갠 직후) |
| 바람 | 실제 풍속·풍향 반영. 풍차 회전, 나무 기울기, 비·눈 방향, 굴뚝 연기 |
| 계절 | 봄 벚꽃, 가을 단풍, 실제 최저기온이 영하 근처면 눈 쌓임. 열대는 여름으로 고정 |
| 예보 | 지금 날씨, 7일 예보(창 너비에 따라 배치 바뀜), 요일별 시간별 그래프·3시간 간격 날씨 |
| 장소 | 현재 위치(macOS CoreLocation), 도시 검색(Open-Meteo 지명 검색) |
| 미리보기 | 설정에서 아무 시간대·날씨·계절을 골라 보기 |
| 위젯 | 바탕화면 고정 / 일반 / 항상 위, 투명도 30~100%, 크기 조절, 우상단·좌상단 이동, 위치·크기 기억, Dock 아이콘 없음, 위젯일 때 30fps |
| 들어가기 모드 | 3인칭 캐릭터로 걷기(클릭·WASD·방향키), 스페이스 점프, 차에 치이면 날아감, 피렌체 대관람차 타기. 캐릭터는 임시 모양 |
| 소리 | 노이즈로 만든 폭포·비·바람 배경음 |
| 자동 업데이트 | 시작 직후와 6시간마다 확인 후 설치, 다시 시작 버튼. 설정에 버전 표시 |
| 기타 | 로그인 시 자동 실행, 웹 버전 쇼케이스 모드(`F` 키, `?showcase`) |

### 나중

- 들어가기 모드 캐릭터 모델: 지금은 몸통·머리·모자만 있는 임시 모양이다. 시안([explore-character.md](explore-character.md))이 정해지면 Blender 스크립트로 바꾼다.
- 재질·조명 개선(가중 법선, 하늘 환경광 PMREM, 꼭짓점 그라데이션, 틸트시프트·블룸 후처리): 원격 `feat/material-quality` 브랜치에 커밋 `5109af4`로만 있고 `main`에 합쳐지지 않았다.
- Windows 현재 위치: 코드에서 macOS 외에는 `unavailable`을 돌려준다([lib.rs](../src-tauri/src/lib.rs) `current_location`). 도시 검색으로 대신한다.
- Windows 코드 서명: README에 "코드 서명이 없어 SmartScreen 경고"라고 적혀 있다.

### 범위 밖

- 원작 모델·코드 재사용: 아이디어만 빌린다.
- 영화 속 움직이는 성 그대로 옮기기: "네 발로 걷는 고철 성"이라는 발상만 가져와 따로 디자인한다.
- 포켓몬 테마: 2026-10-28에 만들었다가 같은 날 되돌렸다([결정기록](결정기록.md)).
- 마을 사람: v0.3.1에서 다섯 테마 모두 뺐다.
- 유료 날씨 API·API 키: 키 없는 Open-Meteo만 쓴다.
- 모바일 앱: 데스크톱 위젯과 웹 버전만 있다.

## 완료·성공 기준

- 늘 띄워 둘 만큼 가볍다: 설치 파일 20MB 안쪽, 위젯은 30fps 상한.
- 빛을 구운 뒤 같은 화질에서 도시 테마 프레임 255 → 1764(커밋 `7dae428`, 개발 글 4장).
- `npm run build`(타입 검사 + 웹 빌드) 통과. 자동 시험 코드는 없다.
- 릴리스 워크플로가 맥 앱의 서명·공증·위치 entitlement를 확인(`codesign --verify`, `stapler validate`, `spctl --assess`)하고 통과해야 올린다.
- "미니어처처럼 보이는지"는 숫자로 잴 수 없어 스크린샷을 보며 정했다(개발 글 "해보고 나서").
- 사용자 수·다운로드 수 같은 지표는 근거 자료가 없어 적지 않는다.
