#날씨를 받아 장면에 반영

sequenceDiagram
  participant M as main.ts
  participant W as data/weather.ts
  participant OM as Open-Meteo
  participant E as scene/env.ts
  participant S as world.ts · Stage
  M->>W: fetchForecast(장소)
  W->>OM: forecast (좌표 소수 2자리, 7일, timezone=auto)
  OM-->>W: current · hourly · daily
  W-->>M: Forecast (날씨 코드 → Condition 10가지)
  M->>E: 시간대 · 날씨 · 계절 · 풍속 · 풍향 계산
  E->>S: 하늘빛 · 해 · 안개 · 바람 값
  loop 매 프레임 (위젯은 30fps 상한)
    S->>S: 라이트맵 × 하늘빛, 해 그림자, 물 · 폭포 · 불빛 · 흔들림 · 비 · 눈
  end
  Note over M: 실패하면 장소를 바꾸지 않고 이전 예보 유지, 연결 끊김 표시

#핵심 파일

파일 설명
src/scene/world.ts 렌더러·카메라·조명, 테마 전환, setFrameCap(위젯 30fps), 크기 바꿀 때 바로 다시 그리기
src/scene/kit.ts Stage 인터페이스, 공용 재질, Sway(바람 흔들림, dt 누적), Waterfall, Floaters
src/scene/baked.ts 라이트맵 셰이더에 skyTint를 곱하는 패치
src/scene/explore.ts 들어가기 모드, three-mesh-bvh
src/data/weather.ts fetchForecast, 지명 검색, Condition·TimeOfDay·Season
src/ui/desktop-settings.ts 창 배치, 투명도, 버전, 자동 업데이트(6시간마다)
src-tauri/src/lib.rs 트레이, 층(get_layer·set_layer), 모서리 붙이기, current_location
src-tauri/src/location.rs CoreLocation, 실패 코드 denied·unavailable·timeout
tools/blender/tile.py 땅 테마 공용 바닥(높이 격자, 지층 옆벽, 물 단면, 먼 풍경, 카메라 높이 격자 mark_top)
.github/workflows/release.yml 매트릭스 빌드, 맥 서명·공증·확인, 파일 이름 정리, latest.json 합치기

#빌드·실행·배포

npm install
npm run dev            # 웹 버전 http://localhost:5173
npm run tauri dev      # 데스크톱 위젯 (Rust 필요: https://rustup.rs)
npm run build          # 타입 검사 + 웹 빌드
blender -b -P tools/blender/island.py -- public/models glb 384   # 테마 모델 다시 만들기
  • 릴리스: package.json·tauri.conf.json·Cargo.toml 버전을 올리고 vX.Y.Z 태그를 푸시한다. Actions가 맥 arm64·x64(서명·공증), Windows x64(NSIS)를 빌드하고 window-scape-<버전>-<플랫폼>.*와 latest.json을 릴리스에 올린다.
  • 필요한 Secrets 이름: MAC_CERT_P12, MAC_CERT_PASSWORD, APPLE_API_KEY_P8, APPLE_API_KEY_ID, APPLE_API_ISSUER, TAURI_SIGNING_PRIVATE_KEY, TAURI_SIGNING_PRIVATE_KEY_PASSWORD(값은 저장소에 없다).
  • 깃 흐름: 큰 작업은 feat/*·docs/* 브랜치에서 PR로 main에 합쳤다(#1 새 룩, #3 덜어내기, #4 README, #5 들어가기 모드). 버전은 main에서 chore: 버전 x.y.z 커밋 뒤 태그. develop 브랜치는 2026-11-05 문서 작업 때 main에서 처음 만들었다.
