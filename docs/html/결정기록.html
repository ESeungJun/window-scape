  • 버린 시도: 시각만 비교, 계절만 보고 눈 쌓기.

#2026-10-27 현재 위치는 CoreLocation으로, 좌표는 소수 2자리

  • 정한 것: macOS 앱에서는 CoreLocation으로 현재 위치를 얻고, Rust에서 좌표를 소수 2자리로 줄인다. 위치는 저장하지 않는다. 로컬 빌드도 번들 전체를 ad-hoc 서명한다.
  • 후보: 웹뷰의 Geolocation API / CoreLocation.
  • 고른 이유: 앱 창 WebKit이 위치 권한을 처리하지 못했다. 링커 서명만 된 실행 파일은 TCC가 앱을 식별하지 못해 위치 권한을 바로 거부했다.
  • 누가 정했나: 이승준.
  • 버린 시도: 앱 안에서 Geolocation API 쓰기.
  • 근거: 81c5f84(위치 좌표 축소·미저장), f2d772e(v0.1.0), 5dd5e68.

#2026-10-28 코드로 만든 도형 대신 Blender 스크립트 모델

  • 정한 것: 나무·집·소품·섬을 Blender 파이썬 스크립트(tools/blender/)로 만들어 glb로 불러온다. glb는 Draco로 압축한다(하늘섬 7MB → 1.4MB, 공용 소품 2.3MB → 0.6MB).
  • 후보: 코드로 상자·원기둥을 쌓은 모델(v0.2) / Blender를 손으로 다루기 / Blender 스크립트.
  • 고른 이유: 코드로 만든 집·나무는 장난감 블록 같은 느낌이 안 빠졌다. 원작처럼 손으로 만든 미니어처 같아야 늘 띄워 두고 싶다. 손 대신 스크립트로 만들었다(스크립트 4,000줄 이상, 개발 글).
  • 누가 정했나: 이승준.
  • 버린 시도: 코드 도형 모델, 그 뒤의 공용 소품 모음(props.glb)·마을 스크립트·절차 지형은 테마별 디오라마로 다시 걷어냄(7dae428).
  • 근거: fb0b978, 1bb25e8, 8f5137b, 7dae428, 개발 글 3장, 목표 표.

#2026-10-28 빛은 굽고 해만 실시간

  • 정한 것: Blender에서 하늘빛과 틈 그늘을 라이트맵으로 굽는다. 앱에서는 라이트맵에 시간대·날씨 하늘빛을 곱하고 해만 실시간으로 비춰 넓게 흐린 그림자를 만든다. 색상표를 고정한다(세이지 잔디, 머스터드·황토 단풍, 테라코타 지붕, 크림 벽).
  • 후보: 실시간 조명 + 실시간 앰비언트 오클루전 / 구운 빛.
  • 고른 이유: 그늘이 부드러워지면서 오히려 가벼워졌다. 같은 화질에서 도시 테마 프레임 255 → 1764.
  • 누가 정했나: 이승준.
  • 버린 시도: 반구광·실시간 오클루전 위주 조명. 재질·조명 후처리 실험(feat/material-quality, 5109af4)은 합치지 않았다.
